# Opak MNG - Sitio Web

Sitio web institucional de Opak MNG.

## Estructura

```
opak-mng-site/
├── public/
│   ├── index.html      # Inicio
│   ├── about.html     # Acerca de
│   ├── artist.html    # Artista Principal
│   ├── services.html  # Servicios
│   ├── blog.html      # Blog
│   ├── contact.html   # Contacto
│   ├── login.html     # Acceso
│   └── assets/
│       ├── images/    # Imágenes del sitio
│       ├── css/       # Estilos
│       └── js/        # Scripts
```

## Páginas

- **index.html** - Página de inicio
- **about.html** - Acerca de la agencia
- **artist.html** - Artista Principal
- **services.html** - Servicios ofrecidos
- **blog.html** - Blog / Noticias
- **contact.html** - Formulario de contacto
- **login.html** - Acceso administrativo

## Uso

Abrir `public/index.html` en un navegador web.
